## 一键包启动

### Windows 用户

直接双击 `一键包启动Webui.bat` 即可，浏览器会自动打开 `http://localhost:8501`。

![一键包启动窗口](图片/一键包启动窗口.png)

> 💡 如果没有自动打开浏览器，请手动访问 `http://localhost:8501`

### Linux 用户

使用一键包内置的 Python 环境启动 WebUI：

```bash
# 进入项目目录
cd Galatea-Core

# 使用内置 python_env 中的 Python 启动 Streamlit
./python_env/bin/python -m streamlit run app.py --server.headless=true --browser.gatherUsageStats=false
```

> ⚠️ Linux 版 `ocgcore.so` 尚未充分测试，如遇引擎问题请在 GitHub Issues 反馈。

## 同步资源与卡库

点击侧边栏进入 **🔄 资源同步中枢**：

1. 勾选 **🃏 更新 CDB卡库与官方 Lua 脚本**
2. 点击 **🚀 立即开始同步**

## 构建语义知识库

## 准备卡组

有多种方式获取卡组：

### 方式一：使用一键包自带的测试卡组

一键包内通常会附带几个 `.ydk` 测试卡组，可直接使用。

### 方式二：手动上传

点击侧边栏进入 **🗃️ 资产与卡组管理 → 📂 卡组与环境管理**：
- 将你的 `.ydk` 文件拖入上传区
- 可建立子文件夹分类管理（如 `tier1_meta`、`fun_decks`）

### 方式三：在线爬取（推荐）

点击侧边栏进入 **🗃️ 资产与卡组管理 → 🌐 在线动态环境构建**：
- 选择目标标签（如 `🏆 TCG 比赛上位`、`⚔️ 竞技天梯` 等）
- 设置抓取数量
- 点击抓取，自动批量下载卡组

![在线爬取卡组](图片/在线爬取卡组.png)

## 调整卡组权重（可选）

点击侧边栏进入 **🗃️ 资产与卡组管理 → ⚖️ 动态环境权重调度**：

- 为每个环境池设置权重（0.0 ~ 10.0）
- 权重越高，AI 越常在该环境中训练
- 可随时动态调整，Worker 下局即生效

![权重调整界面](图片/权重调整界面.png)

> 📖 权重调整和虚拟伪装池的详细说明见 [特殊处理逻辑 - 卡组权重调整](special_handling.md#卡组权重调整global-weights)

## 启动训练

点击侧边栏进入 **⚔️ 启动与监控中枢 → 🔥 发起训练 (Train)**。

### 参数分类概览

Galatea-Core 的训练参数分为三个层级，理解这个分类有助于你更好地调参：

| 层级 | 包含参数 | 特点 |
|------|----------|------|
| 🧠 **大脑结构** | `d_model`, `n_heads`, `n_layers` | 相当于 AI 的脑容量——定义后不能中途修改（模型架构已定型） |
| ⚙️ **训练配置** | `batch_size`, `mini_batch`, `workers`, `timeout`, `async_infer`, `no_compile`, 以及下方 RL 超参数 | 可以在接续训练时随时调整 |
| 🗂️ **环境配置** | 卡组权重、虚拟池、泛用卡池 | 完全与训练模块解耦，可以在训练中实时调整 |

> ℹ️ 恢复训练时，大脑结构参数会自动锁定为存档中的配置。训练配置和环境配置均可自由修改。

### 参数简表

| 参数 | 说明 | 新手推荐值 | 内存/显存影响 |
|------|------|------------|---------------|
| **存档加载器** | 选 "None" 从头训练 | None | - |
| **d_model** | 🧠 特征维度（越大越聪明） | 256 | ⬆️ 显存 |
| **n_heads** | 🧠 注意力头数 （越大参考内容越多）| 4 | ⬆️ 显存 |
| **n_layers** | 🧠 Transformer 层数 （越大思考深度越深）| 2 | ⬆️ 显存 |
| **目标轮数** | 训练总迭代次数 | 1000+ | - |
| **总经验池** | 每次采集步数 | 4096 | ⬆️ 内存（主要） |
| **切片大小** | GPU 训练批量 | 256-512 | ⬆️ 显存（主要） |
| **进程数** | 并行进程数 | 4（按CPU核数） | ⬆️ 内存（主要） |
| **timeout** | Worker 单次采集超时 | 300s | - |
| **异步推断** | ✅ 开启（节省显存） | 开启 | ⬇️ 显存 |
| **禁用编译** | ✅ 开启（Windows 必须） | 开启 | - |

> 💡 **内存/显存调优口诀**：`batch_size` 和 `workers` 吃内存，`mini_batch` 吃显存。内存炸了优先降 workers ，显存炸了优先降 mini_batch 或开启异步推断。batch_size和学习平滑度有关(总学习数据量),不建议太低。workers和minibatch更多是速度上的优化，worker的数量不能大于cpu的物理核心数量！在开启异步推断的情况下可以适当降低。

### 推荐配置方案

#### 🧪 新手测试（快速验证）

| 参数 | 值 |
|------|-----|
| d_model | 128 |
| n_layers | 2 |
| 目标轮数 | 100 |
| 总经验池 | 2048 |
| 切片大小 | 128 |
| 进程数 | 2 |
| timeout | 300 |

#### 🏆 正式训练（追求实力）

| 参数 | 值 |
|------|-----|
| d_model | 512 |

| 目标轮数 | 5000+ |
| 总经验池 | 16384 |

配置完毕后，点击 **🔥 在后台启动训练**。

## 查看训练成果

### 实时日志

训练启动后，在 **⚔️ 启动与监控中枢** 底部可看到实时终端日志和异常警报。

### TensorBoard 曲线

点击侧边栏进入 **📉 训练流形图**，点击 **🚀 启动 TensorBoard** 查看训练曲线：

| 关键指标 | 理想趋势 |
|----------|----------|
| `Train/Total_Loss` | 逐渐下降 |
| `Train/Entropy` | 缓慢下降 |
| `Rollout/Average_Reward` | 逐渐上升 |
| `League_Overall/WinRate_Total` | 逐渐上升 |

### 卡组生态大盘

点击侧边栏进入 **📈 卡组生态大盘**，查看各卡组的胜率统计和克制矩阵。

## 竞技场测试模型

训练完成后，点击 **⚔️ 启动与监控中枢 → 🏟️ 发起竞技 (Duel)**：

1. **出战模型 (P0)**：选择你训练好的 `.pth` 模型
2. **守擂模型 (P1)**：选 "None" 对战 RuleBot
3. 设置对战局数和读心频率
4. 点击 **⚔️ 在后台启动竞技场**

测试结果可在 **📈 卡组生态大盘** 中查看，AI 决策过程可在 **👁️ 全息读心回放** 中回放复盘。

![全息回放](图片/全息回放.png)

## [备用路线] 使用打包包体启动

如果你获取的是他人打包好的 `.gkg` 训练成果包，可以跳过训练直接体验：

1. 进入 **📦 模型部署与打包 → 📤 解包与选择性导入**
2. 将 `.gkg` 包放入本地仓库文件夹
3. 选择解包后，勾选需要导入的模型和知识库文件
4. 点击导入

导入完成后，模型会出现在 `./models/` 目录中，直接转到上方 [竞技场测试模型](#竞技场测试模型) 或 [全息读心回放](#查看训练成果)。
