## 一键包启动

如果你下载的是 **整合一键包**，直接双击 `一键包启动Webui.bat` 即可。

等待几秒钟，浏览器会自动打开 `http://localhost:8501` 进入 WebUI 界面。

![一键包启动窗口](图片/一键包启动窗口.png)

> 💡 如果没有自动打开浏览器，请手动访问 `http://localhost:8501`

---

## 同步资源与卡库

点击侧边栏进入 **🔄 资源同步中枢**：

1. 勾选 **🃏 更新 CDB卡库与官方 Lua 脚本**
2. 点击 **🚀 立即开始同步**

![资源同步](图片/资源同步.png)

等待几分钟同步完成。这会从官方仓库拉取最新的 `cards.cdb` 和 `script/` 目录，确保 AI 掌握最新规则。

---

## 构建语义知识库

点击侧边栏进入 **🧠 语义知识库引擎**：

1. ⚠️ **重要**：勾选 **🌐 从 Github 拉取基础卡库同步**（首次使用必须勾选，可大幅加速解析）
2. 点击 **🧠 开始提取卡片语义**

![语义知识库](图片/语义知识库.png)

> 📖 语义化模块的工作原理和 Hash 聚类算法详见 [特殊处理逻辑 - 语义化模块](special_handling.md#语义化模块semantic-kb)

等待解析完成（首次可能需要几分钟），之后的知识库会被保存到 `knowledge_base.json`。

## 准备卡组

有多种方式获取卡组：

### 方式一：使用一键包自带的测试卡组

一键包内通常会附带几个 `.ydk` 测试卡组，可直接使用。

### 方式二：手动上传

点击侧边栏进入 **🗃️ 资产与卡组管理 → 📂 卡组与环境管理**：
- 将你的 `.ydk` 文件拖入上传区
- 可建立子文件夹分类管理（如 `tier1_meta`、`fun_decks`）

### 方式三：在线爬取（推荐）

点击侧边栏进入 **🗃️ 资产与卡组管理 → 🌐 在线动态环境构建**：
- 选择目标标签（如 `🏆 TCG 比赛上位`、`⚔️ 竞技天梯` 等）
- 设置抓取数量
- 点击抓取，自动批量下载卡组

![在线爬取卡组](图片/在线爬取卡组.png)

## 调整卡组权重（可选）

点击侧边栏进入 **🗃️ 资产与卡组管理 → ⚖️ 动态环境权重调度**：

- 为每个环境池设置权重（0.0 ~ 10.0）
- 权重越高，AI 越常在该环境中训练
- 可随时动态调整，Worker 下局即生效

![权重调整界面](图片/权重调整界面.png)

> 📖 权重调整和虚拟伪装池的详细说明见 [特殊处理逻辑 - 卡组权重调整](special_handling.md#卡组权重调整global-weights)

## 检查特殊宣言池（可选）

点击侧边栏进入 **🗃️ 资产与卡组管理 → 🃏 泛用卡池配置 (142 兜底)**：

- 查看当前池中的泛用卡（默认已包含灰流丽、增殖的G等常见手坑）

## RuleBot 环境压测（可选）

点击侧边栏进入 **⚔️ 启动与监控中枢 → 🛠️ 规则自检压测**：

- 设置压测局数（建议 50-100 局）
- 点击启动，检验引擎和脚本稳定性
- 建议在首次训练前运行一次，确保环境无问题

## 启动训练

点击侧边栏进入 **⚔️ 启动与监控中枢 → 🔥 发起训练 (Train)**。

### 参数简表

| 参数 | 说明 | 新手推荐值 |
|------|------|------------|
| **存档加载器** | 选 "None" 从头训练 | None |
| **d_model** | 特征维度（越大学越聪明） | 256 |
| **n_heads** | 注意力头数 | 4 |
| **n_layers** | Transformer 层数 | 2 |
| **目标轮数** | 训练总迭代次数 | 1000+ |
| **总经验池** | 每次采集步数 | 4096 |
| **切片大小** | GPU 训练批量 | 256-512 |
| **进程数** | 并行进程数 | 4（按CPU核数） |
| **异步推断** | ✅ 开启（节省显存） | 开启 |
| **禁用编译** | ✅ 开启（Windows 必须） | 开启 |

### 推荐配置方案

#### 🧪 新手测试（快速验证）

| 参数 | 值 |
|------|-----|
| d_model | 256 |
| n_heads | 4 |
| n_layers | 2 |
| 目标轮数 | 100 |
| 总经验池 | 4096 |
| 切片大小 | 128 |
| 进程数 | 2 |

#### 🏆 正式训练（追求实力）

| 参数 | 值 |
|------|-----|
| d_model | 512 |
| n_heads | 8 |
| n_layers | 6 |
| 目标轮数 | 5000+ |
| 总经验池 | 8192 |
| 切片大小 | 256 |
| 进程数 | 6-8 |

配置完毕后，点击 **🔥 在后台启动训练**。

![启动与监控中枢](图片/启动与监控中枢.png)

> 📖 完整命令行参数说明见 [功能详解 - 命令行模式](features.md#命令行模式)

## 查看训练成果

### 实时日志

训练启动后，在 **⚔️ 启动与监控中枢** 底部可看到实时终端日志和异常警报。

### TensorBoard 曲线

点击侧边栏进入 **📉 训练流形图**，点击 **🚀 启动 TensorBoard** 查看训练曲线：

| 关键指标 | 理想趋势 |
|----------|----------|
| `Train/Total_Loss` | 逐渐下降 |
| `Train/Entropy` | 缓慢下降 |
| `Rollout/Average_Reward` | 逐渐上升 |
| `League_Overall/WinRate_Total` | 逐渐上升 |

### 卡组生态大盘

点击侧边栏进入 **📈 卡组生态大盘**，查看各卡组的胜率统计和克制矩阵。

## 竞技场测试模型

训练完成后，点击 **⚔️ 启动与监控中枢 → 🏟️ 发起竞技 (Duel)**：

1. **出战模型 (P0)**：选择你训练好的 `.pth` 模型
2. **守擂模型 (P1)**：选 "None" 对战 RuleBot
3. 设置对战局数和读心频率
4. 点击 **⚔️ 在后台启动竞技场**

测试结果可在 **📈 卡组生态大盘** 中查看，AI 决策过程可在 **👁️ 全息读心回放** 中回放复盘。

![全息回放](图片/全息回放.png)

## [备用路线] 使用打包包体启动

如果你获取的是他人打包好的 `.gkg` 训练成果包，可以跳过训练直接体验：

1. 进入 **📦 模型部署与打包 → 📤 解包与选择性导入**
2. 将 `.gkg` 包放入本地仓库文件夹
3. 选择解包后，勾选需要导入的模型和知识库文件
4. 点击导入

导入完成后，模型会出现在 `./models/` 目录中，直接转到上方 [竞技场测试模型](#竞技场测试模型) 或 [全息读心回放](#查看训练成果)。
