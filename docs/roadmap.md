# 🗺️ 后续开发路线

> 本文只记录已确认方向，不表示相关功能已经进入当前稳定训练协议。

## 主框架后续认知补全

- [ ] 设计“已生效效果追踪器”：记录发动方、效果编号、处理结果、无效状态和预计失效边界，使手牌/墓地发动且持续到回合结束的效果可被可靠观测
- [ ] 审计运行时效果描述低位与 Lua 效果创建槽的精确映射；对非常规 `Stringid` 脚本建立显式映射，避免已用效果位只能依赖常规编号约定
- [ ] 将最近发动历史从“最近 8 张发动卡”扩展为结构化事件序列，并评估是否需要覆盖召唤、攻击、移动和选择结果
- [ ] 研究结构化辅助头：战术目标、卡片角色、路线完成率、资源变化和下一状态预测；必须有可验证训练标签或自监督目标，不能把注意力权重直接包装成解释
- [ ] 在全息回放中展示经过校准的辅助输出和反事实评估，并明确区分模型预测、实际事件与解释性推断

## 可分离组卡认知模块

- [ ] 抽离可复用的卡片语义编码接口，并保持对局策略模型可独立训练、部署
- [ ] 构建无序卡组关系编码器，显式区分主卡组、额外卡组、Side Deck、卡片数量和卡片角色
- [ ] 构建 BO3 换备策略与完整构筑编辑策略，动作包括加入、移除、交换和完成，并由规则掩码保证卡组合法
- [ ] 复用 Galatea 对局模型作为执行器和胜率评估器，以模拟结果和反事实胜率差训练卡片协同关系
- [ ] 为组卡层输出卡片关系图、修改前后胜率变化和可复核的增删理由
- [ ] 让 Type 142 宣言池结合当前卡组、Side Deck、对手已公开卡片和组卡层的对手卡组推断动态生成候选；现有泛用池继续作为安全兜底
