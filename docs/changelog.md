## [v3.4.0] - 2026-08-31

### 🧠 中央推理架构重构

- **固定启用中央批量推理**：移除已经失去实际意义的异步推理开关，当前策略与 self 对手统一通过 ZMQ ROUTER、共享内存槽和请求完成号使用同一个中央推理服务
- **Worker 固定使用 CPU**：采集 Worker 不再接收伪设备选项，也不会创建 CUDA 上下文；当前策略与 self 对手均由中央服务推理
- **真实 CPU/CUDA 训练模式**：原设备选项统一为 `--device auto|cpu|cuda`，同时控制中央推理和 PPO 更新设备；`auto` 优先 CUDA，无可用 CUDA 时回落 CPU
- **按设备分离优化路径**：CUDA 保留 pinned memory、非阻塞搬运、TF32、BF16/FP16 与可选 `torch.compile`；CPU 使用普通内存、FP32 和分阶段线程预算
- **联盟 self/hist 分流修正**：新训练的 self 对手直接复制本轮临时权重，不再把内部 `.pt` 文件误送入正式 `.pth` 检查点加载器；hist 对手继续使用 UUID 鉴权的正式检查点

### 📚 接口与文档

- CLI 与 WebUI 同步移除旧 `async_infer`/Worker 设备开关，训练设备统一为 `auto`、`cpu`、`cuda`
- 更新中英文 README、快速开始、功能说明、架构设计与特殊处理文档
- 框架显示版本与 `version.txt` 更新为 `3.4.0`

## [v3.2.0] - 2026-05

### ✨ 重大架构升级

- **🧬 FiLM 全局状态调制**：新增 FiLM Generator，根据当前阶段/回合/LP 等全局信号动态生成 Transformer 各层的缩放(γ)与偏移(β)参数，让网络在不同游戏阶段拥有不同的推理倾向
- **🔀 SwiGLU 门控前馈网络**：将传统 MLP (Linear→ReLU→Linear) 全面替换为 SwiGLU 门控线性单元，采用无偏置设计与 Tensor Core 64 对齐优化，显著提升非线性建模能力
- **⚡ ZMQ 零拷贝进程通信**：使用 ZeroMQ ROUTER 微批处理架构替换原有管道通信，结合锁页内存(pinned memory)的极速 DMA 异步搬运，采集时间减半
- **📦 ONNX 推理加速**：新增 `--use_onnx` 选项，训练时自动同步导出 ONNX 计算图，Worker 端使用 ONNX Runtime 进行极速推理，大幅加速数据采集

### 🔧 功能增强

- **🧵 Worker 线程自适应**：根据系统 CPU/内存实时状态动态调整 Worker 行为
- **🔗 连锁堆栈学习**：将连锁堆栈的历史次序与语义信息纳入训练（chain_pos_embed + 连锁语义槽位），AI 能真正理解连锁逆序结算
- **📍 位置排序学习**：修复了行动选择中卡片位置排序未被纳入学习的问题，现在 #25 排序操作会利用加权位置嵌入

### 🔧 优化

- **⏱️ Worker 耗时审计报告**：新增详细的 Worker 各环节耗时统计（推理/编码/通信等），终端实时输出性能瓶颈诊断
- **📡 读写错峰优化**：数据采集与存储阶段错峰调度，避免 I/O 拥堵导致的帧丢失
- **📚 语义库单次注入**：知识库数据仅首次加载时注入，后续迭代直接复用缓存，减少内存抖动
- 其他底层稳定性与细节优化

### 📦 新增依赖

- `pyzmq` - ZeroMQ 进程通信
- `onnxruntime`  - ONNX 推理加速
