# 📝 更新日志

> 本文档记录 Galatea-Core 的版本更新历史。

## [v3.0] - 2026-05 (大版本更新)

### ✨ 重大新增

- **📦 一键包与便携环境**：内置 Python 3.11 便携环境，完全免配置，下载解压即用
- **🧪 完整文档体系**：全中文图文文档（快速上手、功能详解、架构设计、特殊处理逻辑、更新日志）+ 英文版 README
- **🌐 在线动态环境构建**：对接 YGOProDeck API，支持按赛事/构筑类型自动批量抓取卡组，内置后台守护进程实现定时自动更新
- **🧠 虚拟环境构建器**：跨环境池混合配方系统，可创建任意比例的卡组拼装池，无需物理移动文件即可实现跨环境对战
- **📦 模型部署与打包模块**：支持 `.gkg` 格式的模型包封装与解包导入，包含模型、知识库、泛用池的一键式分享部署

### 🔧 功能增强

- **WebUI 全面升级**：
  - 🗃️ 资产与卡组管理：新增泛用卡池配置、卡组全息阅览、环境权重动态调度、在线抓取模块
  - ⚔️ 启动与监控中枢：全新进程管理（PID 追踪/紧急制动/僵尸进程净化）、实时终端日志双列视图（完整日志+异常警报分离）
  - 👁️ 全息读心回放：SVG 棋盘渲染重构，支持透视幽灵特效、动作箭头连线、实时坐标映射
  - 📉 训练流形图：内嵌 TensorBoard 直接查看 Loss 曲线
  - 📈 卡组生态大盘：多数据源合并分析、双卡组 PK 对比
- **142 权重优先排序**：根据卡片来源（自身卡组 > 已知手牌 > 公开区域 > 泛用池）进行智能优先级排序，大幅提升宣言准确率
- **多选包装ai权重包装**：根据ai单卡打分权重排序组池逻辑，权重分布构建倾向化选择池，提升ai处理大选择可能场景能力

### 🚀 性能优化

- **数据处理逻辑优化**：大幅优化消息解析和特征编码的 CPU 占用
- **全息回放渲染优化**：SVG 层渲染重构，大文件加载速度显著提升
- **WebUI 响应优化**：缓存策略和日志截取逻辑改进，长时运行不卡顿
- **内存管理优化**：多进程 Worker 内存复用改进

### 🔧 底层维护

- **算法逻辑优化**：PPO 训练稳定性提升，奖励函数微调
- **添加 Linux 环境支持**：提供 `ocgcore.so`（未充分测试），扩展跨平台能力
